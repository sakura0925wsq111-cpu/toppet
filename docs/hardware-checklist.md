- 图片中 ¥177 的带电池版本适合做小尺寸桌宠，建议直接用它作为测试板和最终成品主板，避免先买无电池版、之后重复购买。

## 二、到货后必须完成的测试

按以下顺序测试；全部通过后再购买最终成品物料。

1. **通电与充电**
   - USB-C 通电能够正常启动。
   - 电脑能够识别串口或 USB 下载设备。
   - 电池能够充电，拔掉 USB 后仍可工作。

2. **屏幕和触摸**
   - 运行官方出厂固件或示例。
   - 480×480 屏幕无坏点、异常闪烁和触摸漂移。
   - 连续播放桌宠动画至少 30 分钟，不死机。

3. **录音**
   - 双麦克风能够录到清晰语音。
   - 导出或上传 16kHz、16bit、单声道 PCM/WAV 录音。
   - 安静环境下无明显电流噪声。

4. **语音播放**
   - 播放 WAV/PCM 测试音频。
   - 确认实体扬声器是否已经集成、音量是否够用。
   - 播放时没有严重破音、啸叫或持续底噪。

5. **Wi-Fi 通信**
   - 连接 2.4GHz Wi-Fi。
   - ESP32 能访问电脑上运行的测试接口。
   - 连续请求 20 次不频繁掉线。

6. **完整本地模型链路**
   - 按键或触摸开始录音。
   - ESP32 将录音上传到电脑。
   - 电脑完成 ASR → 本地大模型 → 自训练声音 TTS。
   - 电脑把生成的音频返回 ESP32。
   - ESP32 播放回复，同时切换“聆听、思考、说话”表情。

通过标准：从结束说话到开始播放回复，链路稳定运行 20 轮；服务失败时不切换到其他人的 TTS 声音。

## 五、外部计算设备说明

本地大模型不能运行在 ESP32-S3 内。系统还需要一台运行服务的电脑，但测试阶段不必购买新机器。

最低成本做法：

- 使用当前电脑运行 Python 服务。
- ASR 使用 Whisper/faster-whisper 或当前方案。
- 大模型使用 Ollama、LM Studio、llama.cpp 或当前 API。
- TTS 强制使用自己的 GPT-SoVITS/VoxCPM 声音，不设置其他声音回退。

最终送人时，如果桌宠需要在没有电脑的情况下动态对话，需要另外解决常开计算服务：女朋友的电脑、自己的常开电脑、带 GPU 的本地主机或云端 GPU。普通无独显迷你主机不建议在尚未测量模型速度前购买。
